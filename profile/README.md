## LingTTS · Chinese speech synthesis on ESP32-S3

LingTTS turns Chinese text into speech locally on ESP32-S3, without a cloud TTS service.

- Offline Chinese neural speech synthesis with streaming PCM output.
- Examples for device integration and a Wi-Fi hotspot text-to-speech demo.
- Measured resource usage and documented limitations.

LingTTS 是面向 ESP32-S3 的本地中文语音合成引擎：输入文字，设备生成语音，无需云端 TTS。
我们正在准备社区 SDK、示例和接入文档。示例计划开源，核心引擎和模型采用独立许可；具体使用范围以各发布版本附带的条款为准。

Community release materials are in preparation. Examples and integration code are planned to be open source; the core engine and model assets will use separate licenses.
